# Idea template

Copy this into Section 1 of [`IDEA_BACKLOG.md`](./IDEA_BACKLOG.md). Leave
out any line with nothing to say. Say "not decided" rather than guessing.

```markdown
### IB-nn — <short name>

- **Status:** Idea
- **Source:** <who, when, where it came up — a chat, the Ledger, a design
  mock>. <How firm it is: a request, a suggestion, a passing mention.>
- **The idea:** <one or two sentences, in the player's terms>
- **Why it might matter:** <the problem it solves, or the moment it
  improves>
- **Existing facts it would lean on:** <canonical data or functions that
  already exist — never a new calculation passed off as one>
- **Not decided:** <storage, schema, UX, permissions, anything open>
- **Open questions for Shaun:** <product behaviour, rules, data, privacy,
  cost — only the ones that are genuinely his>
- **Constraints if explored:** <Ledger rules it must not break: the frozen
  engine, D4, Reliability's meaning, the April/May display-only history…>
- **Ledger link:** <added when the idea is Approved, Parked or Rejected>
```
