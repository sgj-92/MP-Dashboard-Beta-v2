1Money Padel — player app

Structure & system

Five tabs, each owning one human question. "More" is gone: its contents either became part of Me (settings, doughnuts, deep stats) or became contextual (admin). Every game — from a first request to the final score — lives in one place: Play.

Navigation · one question per tab
Home
What do I need to know right now?
Rating + Tier Rank, anything waiting on me, next game, this month, latest result, club pulse.
Rankings
Where does everyone stand?
Power Rankings by tier. This month: Best Month, League, Merit. W/L and archives below the fold.
Play
What games am I in, and what's next?
One lifecycle list. Request, respond, book, play, score. Find a game. Badge = things waiting on you.
Players
Who is this person?
Search first. Directory, then a profile built around "how do I compare?"
Me
How am I really doing?
Personal dashboard + deep analysis. Doughnuts, settings and (for admins) Admin tools live at the bottom.
The game lifecycle · what players see vs. the system state
Waiting on players

Called out
4/4 agreed, no court. Proposed time shown in italic + dashed "No court" pill. Action: "I've booked a court".
Upcoming
Court booked. Solid date block. Soonest first. The only state that shows on Home as "Next game".
Played
Enter score → result card with "Why it moved". Lives in history, Me and profiles.
Side states
Needs attention — someone backed out; fixture kept, one-tap replace. Archived — call-outs idle 14 days, collapsed.

Key simplifications
— Home shows one rating card, not a hero. First viewport answers questions 1–5.
— Requests, call-outs and fixtures are one list sorted by "what needs doing", not four databases.
— Profiles lead with "You vs them"; rating-engine detail sits behind "More on Rishi".
— Admin controls live in a single contextual "Manage" sheet. Win-probabilities appear only there.
— Gold means "act here" or "this is you". Everything else is ivory on near-black.
